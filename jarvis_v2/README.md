# Jarvis 2.2 — GitHub Codespaces (CPU)

Проект основан на исходном Jarvis V2, а не на новой архитектуре. Модель обучается с нуля на всех пяти JSON в `data/`.

## Запуск в Codespaces
1. Создай приватный репозиторий GitHub и загрузи **содержимое папки `jarvis_v2`** (не сам ZIP). Можно распаковать ZIP локально и загрузить файлы через GitHub или Codespaces.
2. Открой **Code → Codespaces → Create codespace on main**.
3. Открой терминал Codespaces и выполни:

```bash
python -m pip install -r requirements.txt
python train.py
python chat.py
```

Обучение на CPU может занять много часов. Файл `checkpoints/jarvis.pt` и `checkpoints/tokenizer.json` создаются после начала обучения. Чтобы они не исчезли при удалении Codespace, сохрани их отдельно или сделай commit (если размер позволяет). Не добавляй секреты или пароли в репозиторий.

**Важно:** это маленькая символьная модель. Она может запоминать ответы и ошибаться на новых формулировках. При новом обучении словарь строится по всем JSON, поэтому старые веса без миграции словаря не совместимы.
